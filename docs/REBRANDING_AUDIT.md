# Аудит самостоятельного Skrumi

## Перенос исходников

Перед удалением сравнены все 90 файлов старого формата из базового коммита.
55 файлов не имели новой пары: их реализации перенесены в `.skm`.
30 пар примеров различались только именами, путями, комментариями и одним
символом приветствия. Сохранены актуальные версии. Пять файлов стандартной
библиотеки были точными двухстрочными обёртками: удалены только обёртки.

Реальные C++ заголовки перенесены в `include/skrumi`, а реализации Android —
в `org.skrumi.android`; делегирующие фасады удалены. Вычислительные алгоритмы,
инструкции VM, параметры оптимизации и синтаксис не изменялись.

## Состав будущего релиза

| Файл | Назначение |
| --- | --- |
| `Skrumi-windows-x86_64.exe` | Windows GUI installer |
| `Skrumi-linux-x86_64.run` | Статический Linux GUI installer |
| `skrumi-android.aar` | Android SDK |
| `skrumi-android-demo.apk` | Демонстрация Android runtime |
| `skrumi-android-raycaster.apk` | Графический пример и проверяемое приложение |
| `skrumi.vsix` | Расширение VS Code с новой идентичностью |
| `skrumi.xml` | Подсветка Kate |
| `benchmarks.json` | Данные сайта и контроль регрессий производительности |
| `SHA256SUMS` | SHA-256 каждого файла выше |

Zed устанавливается из исходников `editors/zed`; workflow не создаёт готового
пакета Zed, поэтому такой файл не объявлен release asset. Публикация в каталоги
расширений редакторов — отдельная операция. Никакие исторические релизы не удалены.

GUI payload: `skrumi`, `skrumi-lsp`, `std/*.skm`; на Windows также проверенные
maintenance executable/metadata. Брендинг, шрифт с лицензией и инструкции самого
установщика входят в standalone bundle. Runtime содержит лицензии сторонних
библиотек и стандартную библиотеку. Примеры, тесты, SDK-заголовки, архивы сборки
и дублирующая документация в GUI payload не включаются. Android SDK и исходный
APK-упаковщик распространяются отдельно, как и до изменения.

## Безопасность обновления

Сохранены `installer/legacy.skm` и поддержка старых версий журналов транзакций:
это чтение проверенных манифестов владения, необходимое для безопасного обновления
явно выбранной установки. Оно не добавляет старую команду или формат исходников.
Неизвестные каталоги и изменённые пользовательские файлы остаются защищены.
Классическая тема UI с ключом `legacy` также сохранена: это тема оформления,
не режим совместимости языка.

## Контроль оставшихся исторических строк

`tests/test_brand_audit.py` проверяет регистр и варианты написания старого
бренда, расширения и путей. Все совпадения разрешены только в:

- `CHANGELOG.md`: неизменённые исторические записи и запись о breaking change;
- `README.md`: небольшой раздел History;
- `docs/MIGRATION.md`: прежние имена для ручного переноса;
- `tests/test_rebranding.py`: отрицательные проверки CLI, исходников и окружения;
- `tests/test_module_resolution.py`: отрицательная проверка поиска старого формата;
- `tests/test_android_packaging.py`: отклонение старого входного файла и исключение его из payload;
- `tests/test_brand_audit.py`: само правило аудита.

Обычное английское слово «fox» в тестовых строках, названиях животных и URI
стороннего Mozilla CA bundle не является идентификатором продукта. Сертификаты
и лицензии третьих лиц не переименовываются.

## Проверки

Локально выполнены Python-проверки Android staging/trace, release inventory,
версий и VSIX, аудит бренда; браузерные проверки модели UI Builder, редактора,
конструктора, темы и доступности загрузок прошли в Chromium на desktop/mobile.
Нативные CTest, платформенные CI и проверка готового установщика выполняются
в рамках PR; окончательные результаты фиксируются после завершения проверок.
Публикация релиза и merge не выполняются до успешной проверки кандидата.
