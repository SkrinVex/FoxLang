# Skrumi mark

`skrumi-mark.svg` is the primary symbol: an angular S with code-bracket geometry.
It uses a single flat orange (`#ef7b35`) path on a transparent background, with no
embedded raster image, font dependency or external resource. It works on light
and dark backgrounds; keep its square aspect ratio and surrounding clear space.
Recommended minimum display size: 24 × 24 px.

The mark was created for Skrumi by SkrinVex with AI-assisted concept exploration
and a hand-authored SVG. It is distributed under the repository's MIT license.
