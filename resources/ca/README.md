# Встроенное хранилище публичных CA

`mozilla.pem` — неизменённый снимок CA Mozilla, распространяемый проектом curl:

- [Исходный файл](https://curl.se/ca/cacert-2026-08-13.pem).
- [Опубликованная контрольная сумма SHA-256](https://curl.se/ca/cacert-2026-08-13.pem.sha256).
- SHA-256: `f66dff1bdf8f96060b8177976f8b7d9254bc89bc4db933d769f7384d28480bc9`.
- Дата снимка: 2026-08-13, 121 публичный корневой сертификат,
  лицензия MPL-2.0 (см. [LICENSE](LICENSE)).

CMake проверяет хеш и встраивает байты этих публичных сертификатов. Это не закрытые
ключи; они не связаны с локальным хранилищем доверия разработчика или `.env`.
Преобразование сохраняет ограничения сертификатов, записанные в X.509, но
не включает все дополнительные правила доверия Mozilla для браузеров.
Подробнее — в [описании извлечения CA](https://curl.se/docs/caextract.html).

Для обновления скачайте официальный снимок с датой и опубликованную контрольную
сумму, проверьте добавленные и удалённые корневые сертификаты. Обновите хеш
в `cmake/Networking.cmake`, ожидаемое число сертификатов
в `tests/unit/test_certificates.cpp`, сведения об источнике в этом документе
и дату снимка во встроенном лицензионном уведомлении. Запустите все сетевые тесты.
Не копируйте в этот каталог произвольные сертификаты со сборочной машины.

Чтобы распространить проверенное обновление хранилища, пересоберите FoxLang
и заново упакуйте приложения. При запуске `FOXLANG_CA_BUNDLE=/path/to/ca.pem`
заменяет хранилище по умолчанию; `system` явно выбирает хранилище ОС,
а `embedded` — этот встроенный снимок. Linux также учитывает `SSL_CERT_FILE`,
если `FOXLANG_CA_BUNDLE` не задана. Автоматического обновления хранилища через сеть
и неявного отключения проверки сертификатов нет.
